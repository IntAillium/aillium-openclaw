Aillium for Chrome

Let Aillium work in this Chrome, with your logins, while you watch.

Connect to Aillium

In Aillium, open Settings, then Connect Chrome, and create a pairing code. Paste it here. Aillium opens its tabs in a purple Aillium tab group, shows on each page whether it is in control, and stops before anything final (paying, sending, deleting) until you approve.

Stop lets go of every tab and disconnects until you turn it back on. You can also right-click the toolbar icon. Clicking the icon on a tab shares that tab with Aillium.
Advanced: local OpenClaw relay

Only for running OpenClaw on this computer. Leave the pairing code empty to use it.

Default port: 18792. Extension connects to: http://127.0.0.1:<port>/.
